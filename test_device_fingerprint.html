Cara Kerja

Device Fingerprinting: Sistem akan mengumpulkan informasi browser dan device untuk membuat ID yang konsisten, bahkan ketika IP address berubah (misalnya pindah dari WiFi ke mobile data).

Rate Limiting: Setiap endpoint memiliki batasan request per waktu tertentu. Jika melebihi batas, request akan ditolak dengan kode 429.

Konsistensi: Device ID akan tetap sama meskipun user berpindah jaringan, karena menggunakan kombinasi user agent, screen resolution, timezone, canvas fingerprint, dll.
